# Financial Analysis & Transaction Automation Dashboard

## Project Overview
This group project focuses on financial data analysis, transaction processing and interactive business reporting using Power BI, Python, SQL and SQLite.

The solution helps analyze financial performance, monitor payment transactions and identify important business trends through interactive dashboards.

## Project Objectives
- Analyze revenue, expenses and net cash flow.
- Monitor financial performance across branches and departments.
- Analyze payment modes and transaction statuses.
- Identify delayed transactions and average payment delays.
- Present key financial insights through interactive dashboards.

## Tools & Technologies
- **Power BI:** Dashboard development, data visualization, KPIs and interactive filters.
- **Python:** Data processing, cleaning and transaction validation.
- **Pandas:** Data manipulation and preprocessing.
- **SQL:** Financial data querying and analysis.
- **SQLite:** Database management.
- **SQLAlchemy:** Database connectivity and transaction handling.
